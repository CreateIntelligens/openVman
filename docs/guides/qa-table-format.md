# 問答表匯入格式

給客戶或工作人員準備快速問答資料用。後台「知識庫 › 新增資料」可以下載範例檔「範例_常見問題」照著填。

## 檔案

- CSV（UTF-8 或 Big5）或 Excel（`.xlsx`）。
- Excel 每張有資料的工作表都要有「問題」「答案」兩欄；有一張沒有，整本會當成一般文件，不會進快速問答。
- 第一列是欄名，之後一題一列。

## 欄位

| 欄位 | 必填 | 可用的欄名 | 填法 |
|---|---|---|---|
| 問題 | 是 | 問題、題目、question、q | 一格一題，不能換行 |
| 答案 | 是 | 答案、回答、說明、answer、a | 可以多行，但不能有以 `## ` 開頭的行 |
| 語言 | 否 | 語言、language、lang | 中文、英文、西文、日文、韓文、台語，或 zh、en、es、ja、ko、nan。不填由系統判斷 |
| 第一層 | 否 | 第一層、第一层、level1 | 第一層分類名稱，會自動放在該題語言分類底下；同名分類會合併，沒有就新建 |
| 第二層 | 否 | 第二層、第二层、level2 | 第二層分類名稱，放在第一層底下（有填第二層就一定要填第一層） |
| 順序 | 否 | 順序、index、i | 數字，控制匯入後題目在分類裡的排列順序（由小到大） |
| 連結 | 否 | 連結、網址、url | 一個網址 |
| 顯示 | 否 | 顯示、display | 填「否」、no、0、false 就先隱藏，其他或空白都顯示 |
| 圖片 | 否 | 圖片、img | 後台已上傳圖片的名稱。客戶手上的圖檔請先留空，匯入後在題目裡加圖 |

舊的「分類」（`路徑`、`path`）斜線欄寫法仍可使用，但不要和「第一層」「第二層」混在同一列。其他欄位（例如「來源檔」「備註」）不會讀進去，匯入結果會列出被略過的欄名。

### 放進哪個分類

快速回覆最多兩層分類（語言分類不計），用「語言」「第一層」「第二層」三欄指定位置：

| 語言 | 第一層 | 第二層 | 問題 | 答案 |
|---|---|---|---|---|
| 中文 | 服務 | 營業時間 | 服務中心的營業時間是幾點？ | 週一到週五早上九點到下午六點。 |
| 中文 | 服務 | | 有停車位嗎？ | 服務中心後方有收費停車場。 |
| English | Service | Hours | What are the opening hours? | Monday to Friday, 9:00 to 18:00. |

- 專案有對應的語言分類（例如「中文」「English」）時，題目會放進「語言 › 第一層 › 第二層」（只填第一層時放進「語言 › 第一層」）。
- 專案沒有對應的語言分類時，先放在最上層的「第一層 › 第二層」。
- 「第一層」「第二層」都留空時，放在語言分類底下、以檔名命名的分類。

## 多語言

- 中文、英文、西文可以混在同一張表。系統判出不只一種語言時，會一題一題標上語言，放進第一層的「中文」「English」「Español」分類底下。
- 語言分類要先在後台建立，系統不會自己建；還沒有的語言會先放在最上層，匯入結果會提示。
- 填了「語言」欄的以填的為準，看不懂的值會提示並照整份的語言處理。
- 同名的表第一次匯入時只有一種語言，之後重傳才加了其他語言的題目，新題會先跟原本的題目放在一起，結果會提示。要依語言分開，請改檔名重新上傳。
- 一般文件（手冊、說明）不用轉成表格，直接上傳 Word、PDF、Markdown，內容不會被翻譯。

## 匯入會被擋下的情況

整份不匯入，結果會寫明原因（也不會建立任何分類或寫入檔案）：

- 同一列同時填了「分類」和「第一層」或「第二層」。
- 同一列只填了「第二層」、沒有填「第一層」。
- 「分類」（`path`）去掉開頭的語言分類名稱後超過兩層（例如 `中文/A/B/C` 或 `A/B/C`）。
- 有列只有答案、沒有題目，或同一個題目出現兩次、答案不同（答案相同只算一題）。這些問題都會一次列出所有有問題的題目，不會只列前幾題。
- 答案裡有以 `## ` 開頭的行或沒有收尾的 ```` ``` ````，或題目有換行。同樣一次列出所有這類題目。
- 重傳同名的表時，舊題目的答案被改掉（要改答案請在後台改）。會列出衝突的題目。

## 匯入成功後的提示

結果會列出要回頭看的地方：沒讀進去的欄位、看不懂的語言值、還沒有的語言分類、沒有答案的題目、找不到的圖片。CSV 或 Excel 缺「問題」「答案」欄而被當成一般文件時，也會說明原因。

同名的表再傳一次是加上新題目，原本的題目都留著；要刪題目請在後台刪。同一題的答案和現有的不同時，整份都不會匯入，結果會列出是哪幾題，改好再傳一次。
