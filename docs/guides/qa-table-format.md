# 問答表匯入格式

給客戶或工作人員準備快速問答資料用。後台「知識庫 › 新增資料」可以下載範例檔「範例_常見問題」照著填。

## 檔案

- CSV（UTF-8 或 Big5）或 Excel（`.xlsx`）。
- Excel 每張有資料的工作表都要有「問題」「答案」兩欄；有一張沒有，整本會當成一般文件，不會進快速問答。
- 第一列是欄名，之後一題一列。

## 欄位

| 欄位 | 必填 | 可用的欄名 | 填法 |
|---|---|---|---|
| 問題 | 是 | 問題、題目、question、q | 一格一題，不能換行 |
| 答案 | 是 | 答案、回答、說明、answer、a | 可以多行，但不能有以 `## ` 開頭的行 |
| 語言 | 否 | 語言、language、lang | 中文、英文、西文、日文、韓文、台語，或 zh、en、es、ja、ko、nan。不填由系統判斷 |
| 第一層 | 否 | 第一層、第一层、level1 | 第一層分類名稱，會自動放在該題語言分類底下；同名分類會合併，沒有就新建 |
| 第二層 | 否 | 第二層、第二层、level2 | 第二層分類名稱，放在第一層底下（有填第二層就一定要填第一層） |
| 順序 | 否 | 順序、index、i | 數字，控制匯入後題目在分類裡的排列順序（由小到大） |
| 連結 | 否 | 連結、網址、url | 一個網址 |
| 顯示 | 否 | 顯示、display | 填「否」、no、0、false 就先隱藏，其他或空白都顯示 |
| 圖片 | 否 | 圖片、img | 後台已上傳圖片的名稱。還沒上傳的圖可以在上傳後的檢查畫面直接補傳，或先留空、匯入後在題目裡加圖 |

舊的「分類」（`路徑`、`path`）斜線欄寫法仍可使用，但不要和「第一層」「第二層」混在同一列。其他欄位（例如「來源檔」「備註」）不會讀進去，匯入結果會列出被略過的欄名。

## 上傳後的檢查畫面

新上傳或從等待匯入區選擇匯入時，只要含有問答表，就會打開「匯入前檢查」。只有一般文件時會直接匯入。檢查失敗時，檔案留在等待匯入區並顯示錯誤。畫面依序顯示以下內容。

1. **摘要**顯示「新題目 N、重複（答案相同）M、重複（答案不同）K、檔案內重複 D、格式錯誤 E」。同一題出現多次時，每列都列入檔案內重複數，題數只算一題。內容不同的重複列會列為格式錯誤。
2. **格式錯誤**：有格式錯誤的檔案會以紅底列出所有問題，並停用勾選（旁邊提示「請改好檔案後重新上傳」）。
3. **答案不同的題目**會並排顯示「原本的答案」與「新檔案的答案」，手機改為上下排。兩邊不同的字元會標色，任一答案超過 2,000 字元時顯示原文。每題一開始都未選，可按「重複的全部覆蓋」或「重複的全部保留原本」套用後，再逐題更改。
   - **覆蓋**會更新答案。新檔案填了圖片或連結就更新對應欄位，留白的欄位則保留原值。題目沿用原本的文字、隱藏狀態與分類位置。
   - **保留原本**會保留現有題目與答案。
   - **兩題都留（新的會先隱藏）**：現有那一題不動，新檔案那一列以「原題目（新）」新增進文件並先設為隱藏（若「（新）」已存在則依序用「（新2）」），方便工作人員之後再整理。
   - **稍後調整**會保留現有內容，在結果的「待處理」列出新答案和封存的原始檔案路徑（廠商帳號不顯示路徑）。點題目會開啟原題的編輯面板，旁邊會顯示新檔案的答案。
4. **找不到的圖片**：表裡填了專案還沒有的圖片名稱時，每張圖會列出一列與用到它的題目，可按「補傳圖片」直接選圖上傳並預覽縮圖；沒補傳也可以匯入，那幾題就沒有圖片。
5. **放到哪裡**：以縮排樹狀預覽這次會建立或用到的分類與各分類題數，新建的分類標示「新」。

勾選要匯入的檔案裡，衝突題都選完後才能按「匯入」；取消勾選的檔案不會匯入，不用選。按鈕旁會提示「還有 N 題沒選」。確認後會送出沒有格式錯誤且已勾選的檔案。按「取消」會將檔案留在等待匯入區。

### 放進哪個分類

快速回覆最多兩層分類（語言分類不計），用「語言」「第一層」「第二層」三欄指定位置：

| 語言 | 第一層 | 第二層 | 問題 | 答案 |
|---|---|---|---|---|
| 中文 | 服務 | 營業時間 | 服務中心的營業時間是幾點？ | 週一到週五早上九點到下午六點。 |
| 中文 | 服務 | | 有停車位嗎？ | 服務中心後方有收費停車場。 |
| English | Service | Hours | What are the opening hours? | Monday to Friday, 9:00 to 18:00. |

- 專案有對應的語言分類（例如「中文」「English」）時，題目會放進「語言 › 第一層 › 第二層」（只填第一層時放進「語言 › 第一層」）。
- 專案沒有對應的語言分類時，先放在最上層的「第一層 › 第二層」。
- 「第一層」「第二層」都留空時，放在語言分類底下、以檔名命名的分類。

## 多語言

- 中文、英文、西文可以混在同一張表。系統判出不只一種語言時，會一題一題標上語言，放進第一層的「中文」「English」「Español」分類底下。
- 語言分類要先在後台建立，系統不會自己建；還沒有的語言會先放在最上層，匯入結果會提示。
- 填了「語言」欄的以填的為準，看不懂的值會提示並照整份的語言處理。
- 同名的表第一次匯入時只有一種語言，之後重傳才加了其他語言的題目，新題會先跟原本的題目放在一起，結果會提示。要依語言分開，請改檔名重新上傳。
- 一般文件（手冊、說明）不用轉成表格，直接上傳 Word、PDF、Markdown，內容不會被翻譯。

## 匯入會被擋下的情況

整份不匯入，結果會寫明原因（也不會建立任何分類或寫入檔案）：

- 同一列同時填了「分類」和「第一層」或「第二層」。
- 同一列只填了「第二層」、沒有填「第一層」。
- 「分類」（`path`）去掉開頭的語言分類名稱後超過兩層（例如 `中文/A/B/C` 或 `A/B/C`）。
- 有列只有答案、沒有題目，或同一個題目出現兩次、答案不同（答案相同只算一題）。這些問題都會一次列出所有有問題的題目，不會只列前幾題。
- 答案裡有以 `## ` 開頭的行或沒有收尾的 ```` ``` ````，或題目有換行。同樣一次列出所有這類題目。
- 重傳同名的表時，舊題目的答案被改掉且沒有在檢查畫面指定處理方式（直接呼叫 API 未帶 `decisions`）。會列出衝突的題目。

## 匯入成功後的提示

結果會列出要回頭看的地方：沒讀進去的欄位、看不懂的語言值、還沒有的語言分類、沒有答案的題目、找不到的圖片，以及檢查畫面選了「稍後調整」的題目與新答案、選了「兩題都留」新增的隱藏題目。CSV 或 Excel 缺「問題」「答案」欄而被當成一般文件時，也會說明原因。

同名的表再傳一次是加上新題目，原本的題目都留著；要刪題目請在後台刪。同一題的答案和現有的不同時，可在上傳後的檢查畫面逐題決定要覆蓋、保留原本、兩題都留或稍後調整。

## 匯出

在後台知識庫上方按「匯出」可以下載目前的快速回覆 Excel 檔（`.xlsx`，工作表名稱「快速回覆」）。匯出的欄位和這份匯入格式相同（`語言`、`第一層`、`第二層`、`問題`、`答案`、`圖片`、`連結`、`顯示`、`順序`），改完可以直接再上傳；同一題掛在多個分類會分成多列，還沒放進任何分類的題目排在最後、分類與順序留空。

重傳匯出檔時請注意：

- 上傳時系統會照檔名存成一份問答表，所以直接把匯出檔傳回原本的專案，會多出一份新的問答表。
- 同樣的題目如果已經在原本的分類裡，不會重複掛上去，匯入結果會把它們列在「分類裡已有同名題目」。
- 原本同時掛在多個分類的題目，匯出時會各列一筆，但上傳進空專案時匯入只會掛進其中一個分類；需要多分類掛載時，匯入後請在後台補掛。
- 不同文件裡有同一個題目、但答案不一樣時（例如「門診 › 營業時間？」和「藥局 › 營業時間？」），匯出檔會有兩列同題不同答案，整份上傳會被擋下。上傳前請把題目改成不同的字，例如「門診營業時間？」「藥局營業時間？」。
- 分類的「前台顯示」開關不會跟著匯出；匯入後新建的分類都是顯示中，原本隱藏的分類要在後台重新關掉。題目本身的顯示（`顯示` 欄）會保留。
- 不是語言分類的最上層分類（例如「常見問題」），重傳時會放到該題語言的分類底下（例如「中文 › 常見問題」）。
- 還沒放進任何分類的題目（包含刻意從選單拿下的題目），重傳時會放進以檔名命名的分類，前台看得到；不想讓訪客看到的請先刪掉那幾列，或匯入後在後台拿下。
