# 問答表匯入格式

給客戶或工作人員準備快速問答資料用。後台「知識庫 › 新增資料」可以下載範例檔「範例_常見問題」照著填。

## 檔案

- CSV（UTF-8 或 Big5）或 Excel（`.xlsx`）。
- Excel 每張有資料的工作表都要有「問題」「答案」兩欄；有一張沒有，整本會當成一般文件，不會進快速問答。
- 第一列是欄名，之後一題一列。

## 欄位

| 欄位 | 必填 | 可用的欄名 | 填法 |
|---|---|---|---|
| 問題 | 是 | 問題、題目、question、q | 一格一題，不能換行 |
| 答案 | 是 | 答案、回答、說明、answer、a | 可以多行，但不能有以 `## ` 開頭的行 |
| 語言 | 否 | 語言、language、lang | 中文、英文、西文、日文、韓文、台語，或 zh、en、es、ja、ko、nan。不填由系統判斷 |
| 分類 | 否 | 分類、路徑、path | 用 `/` 分層，例如 `產品/沉水泵浦`；同名分類會合併，沒有就新建 |
| 連結 | 否 | 連結、網址、url | 一個網址 |
| 顯示 | 否 | 顯示、display | 填「否」、no、0、false 就先隱藏，其他或空白都顯示 |
| 圖片 | 否 | 圖片、img | 後台已上傳圖片的名稱。客戶手上的圖檔請先留空，匯入後在題目裡加圖 |

其他欄位（例如「來源檔」「備註」）不會讀進去，匯入結果會列出被略過的欄名。

## 多語言

- 中文、英文、西文可以混在同一張表。系統判出不只一種語言時，會一題一題標上語言，放進第一層的「中文」「English」「Español」分類。
- 語言分類要先在後台建立，系統不會自己建；還沒有的語言會先放在最上層，匯入結果會提示。
- 填了「語言」欄的以填的為準，看不懂的值會提示並照整份的語言處理。
- 同名的表第一次匯入時只有一種語言，之後重傳才加了其他語言的題目，新題會先跟原本的題目放在一起，結果會提示。要依語言分開，請改檔名重新上傳。
- 一般文件（手冊、說明）不用轉成表格，直接上傳 Word、PDF、Markdown，內容不會被翻譯。

## 匯入會被擋下的情況

整份不匯入，結果會寫明原因：

- 有列只有答案、沒有題目，或同一個題目出現兩次、答案不同（答案相同只算一題）。這兩種會一次列出所有有問題的題目，不會只列前幾題。
- 答案裡有以 `## ` 開頭的行，或題目有換行。會指出第一個有問題的題目。
- 重傳同名的表時，舊題目的答案被改掉（要改答案請在後台改）。會列出衝突的題目。

## 匯入成功後的提示

結果會列出要回頭看的地方：沒讀進去的欄位、看不懂的語言值、還沒有的語言分類、沒有答案的題目、找不到的圖片。CSV 或 Excel 缺「問題」「答案」欄而被當成一般文件時，也會說明原因。

同名的表再傳一次是加上新題目，原本的題目都留著；要刪題目請在後台刪。
