# 專案專屬 Gemini 金鑰

狀態：Draft

## 範圍與規則

- 開發／測試專案未綁定時沿用共用 Gemini 設定；正式專案可由 ROOT 綁定專屬金鑰。
- 已綁定的專案不因金鑰失效、無法解密或查詢失敗改借共用 Gemini 金鑰。
- 不新增輪替 key 池或用量上限；其他供應商的既有備援規則維持。
- 金鑰加密保存在 Backend；前端只取得名稱、遮罩、來源與設定狀態。
- 金鑰切換、快取與用量歸屬按專案隔離。Live 每段會話固定金鑰；更新於新會話生效。

## 實作

- Backend：專案憑證資料表、ROOT 管理 API、內部專案憑證解析。
- Brain：主對話與模型探索、Live、語音語言判斷及背景 Gemini 呼叫採用專案憑證。
- 語音：Gemini 串流 ASR、Gemini TTS 與台語語言判斷傳遞專案歸屬。
- 後台：專案頁新增 Gemini 金鑰設定，可儲存／更換／明確改回共用。
- 外部 Avatar SDK 與前台不收取供應商金鑰，由已驗證專案上下文在伺服器解析。

## 驗證

- 專案 A／B／未綁定三種情境、加密與明文不外洩、ROOT 權限、更新與刪除。
- 並行請求與快取不串用、專屬失效與解密失敗不使用共用憑證。
- 聊天／SSE／Live／ASR／TTS 的實際傳輸選用正確憑證。
- 部署後從正式入口驗證後台完整設定流程、非 ROOT 隔離及實際請求與用量歸屬。

本文件在使用者確認前維持 Draft；各項驗證結果完成後記錄實際證據。
